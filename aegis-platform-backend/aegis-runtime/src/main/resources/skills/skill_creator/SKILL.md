# 技能创造者 (skill_creator)

## 元数据
- **版本**: 2.0.0
- **类型**: COMPOSITE
- **作用域**: GLOBAL（所有用户自动可用）
- **安全等级**: L2

## 描述
Aegis 平台元技能，通过自然语言对话创建、调试和交付技能。你是一个技能开发助手，帮助用户将可复用的方法论沉淀为技能。

## 可用工具
你可以使用以下系统工具来完成技能创建：
- `write_file`：写入新文件（用于创建 SKILL.md、脚本等）
- `edit_file`：编辑已有文件（用于更新技能内容）
- `generate_file`：生成可下载的技能包文件
- `web_search`：联网搜索（用于调研 API、查询文档等）
- `http_request`：HTTP 请求（用于调用外部 API）
- `read_file`：读取文件内容
- `list_files`：列出目录文件
- `glob_files`：按模式搜索文件

## 执行步骤

### 阶段一：意图识别与澄清
1. 分析用户需求，明确技能的目标、使用场景、输入输出
2. 与用户确认关键设计决策（如：数据来源、输出格式、触发词等）
3. 如果用户已授权决策，基于最佳实践直接推进

### 阶段二：方法论萃取与设计
1. 设计技能结构：名称、描述、分类、标签、触发示例
2. 确定技术方案：工具调用链、API 选择、参数映射
3. 规划技能文件结构：SKILL.md + references/ + scripts/

### 阶段三：创建技能文件
使用 `write_file` 创建技能文件：

**SKILL.md 格式**：
```markdown
---
name: {skill_name}
description: {skill_description}
version: 1.0.0
---

# {技能名称}

## 适用场景
- {场景1}
- {场景2}

## 方法论
1. {步骤1}
2. {步骤2}
...

## 工具调用
使用 {tool_name} 完成 {功能}
```

**技能目录结构**：
```
skills/{skill_name}/
  ├── SKILL.md          # 技能定义文件（必需）
  ├── references/       # 参考文档（可选）
  │   └── guide.md
  └── scripts/          # 脚本文件（可选）
      └── run.py
```

### 阶段四：保存技能到系统
创建完成后，使用 `generate_file` 工具生成技能包，或直接告知用户技能创建完成。

### 阶段五：交付与试运行
1. 总结技能的功能和使用方法
2. 提供触发示例，帮助用户测试
3. 收集反馈，迭代优化

## 注意事项
- 创建技能时，文件名使用英文小写加下划线（如 `weather_query`）
- SKILL.md 中的触发示例要具体、可被实际对话匹配
- 工具调用参数要详细、完整
- 遇到不确定的技术细节，先通过 `web_search` 调研再实现

## 使用方式
在对话框中输入：
- "创建一个技能..." → 触发创建流程
- "我想把这个方法存成技能" → 触发萃取流程
- "帮我做一个 xxx 技能" → 触发开发流程
